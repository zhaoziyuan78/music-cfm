Unpaired counterfactual symbolic music

编码音乐，反演共享噪声，干预风格。

Music-SCM 将符号音乐反事实建模为条件生成映射的逆向与正向组合：先在源风格条件下从原曲 latent 反演个体噪声，再保持该噪声不变，仅替换目标风格条件并重新生成。

Problem formulation

无配对训练下的共享噪声结构

输入与目标

训练数据只包含独立的 MIDI 片段及其 style label，不要求同一首曲子的多个风格版本。模型学习每个条件分布，而不是学习 source-target 成对映射。

UNPAIREDSYMBOLIC MIDISTYLE INTERVENTION

反事实操作

z = E_VAE(x)
u = F⁻¹_source(z)
z_cf = F_target(u)
x_cf = D_VAE(z_cf)

共享变量是 abducted noise u；干预只发生在 condition。

Stage 1 学习条件生成分布；Stage 2 约束反演噪声的风格独立性、先验匹配和 source-condition round trip。Evaluation 将风格变化、非风格内容保留、噪声泄漏和 MIDI 合法性分别报告。

Tokenizer

VAE 训练目标

L_VAE = CE(x, x̂)
+ β(t) · meanⱼ max(KLⱼ, 0.05)

β(t): 0 → 1e−4 over 20k steps

训练从 posterior 采样；validation、cache 和 transport 固定使用 posterior mean。

优化与防止 posterior bypass

  • AdamW：lr 1e−4，weight decay .01，betas (.9,.95)
  • 5k warmup + cosine，BF16，gradient clip 1.0，EMA .999
  • decoder token dropout .15，迫使 decoder 使用 latent
  • length bucketing + activation checkpointing
  • 32 samples/GPU；100k steps 或 8 epochs

自回归解码

greedy 或 top-p 逐 token 生成；EventGrammar 屏蔽不合法的 BAR/BEAT、instrument、melodic/drum pitch 转移。每层缓存 projected self-attention K/V，并预计算 latent-memory K/V，将重复前缀计算降为标准的增量 attention。

Latent interface

冻结 codec，缓存 posterior mean，统一 condition

FP16 latent cache

encoder inference 输出 raw posterior mean，pitched shape 为 `64 × 512`。每 shard 最多 8,192 samples；index 保留 sample、split、style、genre、emotion 与 shard offset。

RAW MEANFP168192/SHARD

metadata 保存 codec checkpoint/config、tokenizer、manifest、normalization、latent shape 与 overlength policy 的 hash。

per-token-v2 normalization

64 个 learned query 位置分别统计 512 channels；统计仅由 train split 流式计算，validation/test 复用相同参数。

μ, σ ∈ R⁶⁴ˣ⁵¹²
z̃ᵢⱼ = (zᵢⱼ − μᵢⱼ) / σᵢⱼ

Stage 1 · conditional flow matching

共享 AdaLN DiT 学习风格条件向量场

Latent DiT backbone

  • latent input/output channels：512
  • hidden width：768；10 blocks；12 attention heads
  • MLP ratio 4；dropout 0
  • sinusoidal time embedding + two-layer time MLP
  • dataset/task/style/factorial embeddings 相加
  • 每个 block 产生 attention/MLP 的 shift、scale、gate
  • vector-field output projection zero-initialized

Independent CFM objective

ε ~ N(0, I),  t ~ Uniform(0,1)
zₜ = (1−t)ε + tz
v* = ∂zₜ/∂t = z − ε

L_CFM = E ||vθ(zₜ,t,c) − v*||²

loss 按 style frequency 的 inverse square-root 加权。主目标只使用有效 factual condition/path。

ShardBatchSampler 保持磁盘 locality，同时先按 song 等权、再从同一 song 的多个 segment 中轮换选择窗口。held-out validation 从每个 style 取固定样本，用相同噪声生成条件 endpoint，分别计算 raw/EMA 的 class-conditional MMD 与 sliced Wasserstein distance。

ABDUCTION

t = 1 → 0

在 source condition 下对 ODE 反向积分：`z_source → u`。

PREDICTION

t = 0 → 1

在 source condition 下重建 factual latent，或在 target condition 下生成 counterfactual latent。

默认 solver 是 32-step fixed-grid Heun。系统记录实际 NFE；Heun 的 predictor/corrector 通常使 NFE 高于名义 solver steps。

Stage 2 · exogeneity fine-tuning

约束共享噪声，而不放弃基础生成目标

Stage 2 从 Stage 1 EMA 权重初始化。每个 step 都保留基础 CFM/DDIM loss；每两个 step 额外执行可微 4-step abduction 和同条件 reconstruction，在全局 DDP batch 上施加外生性和 round-trip 正则。

L = L_base + r(t) [
  λ_h · HSIC(u, s)
 + λ_p · SWD(u, N(0,I))
 + λ_c · MMD_cross-class(u)
 + λ_r · (L1 round-trip + 0.1 · cosine round-trip)
]

λ_h = .01, λ_p = .005, λ_c = .01, λ_r = .25

动态多视图 noise

每 step 重采样 3 个 `32768→128` Rademacher projections，并加入 per-token mean/std summary 与随机 `8 tokens × 32 channels` raw block。

全局 DDP 正则

features 通过 differentiable all-gather 合并，labels 同步 gather；HSIC、SWD 和 cross-class MMD 在四卡完整 batch 上计算。

层级 balanced sampler

每 GPU `4 styles × 16 samples`，采样顺序为 style → unique song/sample_id → one segment。

12K STEPSLR 2E−5WARMUP 500RAMP 2000EMA .999 / 10INVERSE 4

checkpoint interval 为 1,000 step。每次 checkpoint 同时验证 raw 与 EMA：conditional endpoint MMD/SWD、held-out noise HSIC/SWD/cross-class MMD 和 source-condition round trip。

Baselines & ablations

使用同一 latent 接口的 transport 家族

OT-CFM

网络、batch 和训练预算与 I-CFM 对齐，仅把 Gaussian–factual coupling 换成 within-style minibatch OT。cost 在 128D 投影上计算，使用 Hungarian 一对一 assignment。

Conditional DDIM

8 层、width 512、8 heads 的 latent DiT；cosine schedule、1,000 train timesteps、epsilon prediction、deterministic `eta=0`。

DDIM inversion

vanilla inversion 作为基础方法；fixed-point inversion 每个离散时间步最多迭代 3 次，容差 `1e−5`，并记录实际 NFE。

Weak latent split

固定可逆正交旋转把 512 channels 分成 256 conserved 与 256 editable，仅对 editable 子空间运行 CFM。

Independent flows

每个 style 使用独立 flow，作为“没有共享条件向量场/共享噪声语义”的结构负对照。

Shuffled labels

以固定 seed 对训练标签做持久化 permutation，用于检验评价是否依赖真实条件监督。

Artifact contract

每个 transition 保存 `source.mid`、`counterfactual.mid`、`abducted_noise.pt` 与 metadata。metadata 包含 sample/source/target、condition schema、factorial axis、checkpoint provenance、solver steps 和 inverse/forward NFE；完整 artifact 可在重跑时跳过。

Unpaired evaluation

风格、内容、外生性和 MIDI 质量分开评价

① CLaMP 2 风格变化

generated MIDI 转为 lossless MTF；官方 M3/CLaMP 2 extractor 产生归一化 MIDI embedding。每个 style label 用固定模板构造 text embedding：

“This is a piece of {style} music.”
  • generated ↔ target-style cosine
  • generated ↔ source-style cosine
  • target-minus-source similarity margin
  • target prompt 是否为全部 style 中的 argmax

XMIDI genre pipeline 只比较 style/genre prompt，不将 emotion 等辅助标签纳入风格变化判断。

② 非风格内容保留

  • pitch-class histogram cosine
  • transposition-invariant top-line melody contour cosine
  • interval、duration、onset、program、drum 与 scalar descriptor cosine
  • source/generated note-density ratio
  • source/generated tempo ratio

各指标独立输出，不合并成单一 content score。

③ Abducted-noise leakage

每个 unique source song 只保留一份 noise。评估器重新训练、并与 Stage 2 adversary 独立：

  • standardized logistic regression
  • 两层 MLP `(128,64)`
  • 沿 latent-token 维的两层 Conv1D temporal probe
  • HSIC、classwise moments、Gaussian SWD、pairwise two-sample accuracy

④ MIDI 质量

  • source/generated MIDI validity 与具体错误
  • note count、duration beats 与 note density
  • unique pitch classes 与 pitch range
  • non-positive-duration ratio
  • Groove 的 drum-onset F1 扩展

Codec 与 transport 内部验证

Codec

token CE/accuracy、free-running token accuracy、note-event multiset F1、exact sequence、EOS/grammar validity、zero/shuffled-latent degradation。

Transport

conditional endpoint MMD/SWD、factual round trip、noise recovery、HSIC/SWD/MMD、16/32/64-step NFE 与 runtime、跨 seed ambiguity。

Evaluation 不训练 in-domain Transformer style classifier 作为主指标；风格判断使用 CLaMP 2 的 MIDI-text embedding，noise probe、content preservation 和 MIDI quality 保持为独立评估维度。
Training system

DDP、日志、rolling checkpoint 与一键 pipeline

训练状态

`last.pt` 保存 raw/EMA、optimizer、scheduler、GradScaler、global step、epoch、batch cursor、world size、RNG state、完整 config 和 provenance。

可观测性
